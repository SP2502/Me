About

Curiosity turned into systems.

I started making projects because I wanted to grow with the world as the world is growing. Because I am curious.

That curiosity gradually moved from simply writing code to understanding what happens between components: how services communicate, how APIs abstract complexity, how systems react when something fails, and how multiple AI models and tools can work together.

I'm still learning, so many of these projects are experiments as much as they are software. Building them gives me a way to understand ideas by actually putting them under pressure.

01 / Infrastructure

Universal

Flagship · Early development

A weather-data infrastructure system designed to connect multiple providers behind one consistent API.

Why

Weather data often comes from different providers with different interfaces and limitations. Universal explores how those differences can be hidden behind a consistent system.

Exploring

Provider selection, location resolution, data normalization, fallback behavior and service reliability.
