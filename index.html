Universal

Weather infrastructure without provider-specific complexity.

Universal is a weather-data infrastructure project I'm refining to make weather data easier to consume through a consistent API. It handles the complexity behind the scenes: resolving locations, selecting weather providers, falling back when a provider fails, and normalizing the resulting data.
