FLAGSHIP PROJECT

Universal

Weather-data infrastructure designed to provide one consistent API across multiple weather providers.

Universal takes coordinates, resolves the location, determines which provider can serve the request, falls back when necessary, and normalizes the resulting weather data into a consistent interface.
