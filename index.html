About

Curiosity turned
into systems.

I'm a Class 11 student interested in understanding how software and AI systems actually work.

I don't want to only use software. I'm interested in what happens underneath it — how APIs communicate, how services interact, how systems handle failures, how AI systems coordinate multiple steps, and how rough experiments can become usable systems.

I started making projects because I wanted to grow with the world as the world is growing. Because I am curious.

Technology keeps changing, especially in AI and software. Building is my way of learning alongside that change rather than only watching it happen.

01
Flagship Weather Infrastructure

Universal

Weather-data infrastructure through provider abstraction.

Universal explores how applications can access weather data without needing to understand every individual weather provider.

It acts as an abstraction layer that can resolve coordinates, select a provider, handle failures, fall back to another provider, normalize responses, and expose a consistent interface.

AI Systems Open Source

Cortex

An autonomous deep-research system.

Cortex explores how an AI system can move beyond a single model call and coordinate a longer research workflow.

The system is designed around planning, task decomposition, research, evidence collection, comparison, reasoning, and structured synthesis.
